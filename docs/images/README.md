# Images

Graphics used on the project page and in the documentation.

| File | What | Source |
|---|---|---|
| `Gail.svg` | the logo (1024×1024 canvas, vector) | master; the PNGs below are exported from it |
| `Gail-large-1024.png`, `Gail-small-128.png`, `Gail-tiny-32.png` | logo exports: large, avatar, favicon | `Gail.svg` |
| `GAIL-header.png` | header artwork, 2172×724 (logo, wordmark, tagline) | master |
| `GAIL-header-1600.png` | the header at 1600 px, 256 colours (what the README embeds; a third of the size) | `GAIL-header.png` |
| `social-preview.png` | 1280×640 for GitHub's *Settings → Social preview* (shown when the repo is linked) | `GAIL-header.png` |
| `throughput.svg` / `.png` | throughput chart in the README | generated by `scripts/throughput_chart.py` from the table in [BENCHMARKS.md](../BENCHMARKS.md); re-run it after a benchmark refresh |

Keep sources (SVG, design files) next to the exported PNGs. Screenshots and large
renders belong in a release, not here: the repository is cloned by everyone who builds
from source.
